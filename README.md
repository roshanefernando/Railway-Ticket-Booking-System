# Railway Ticket Booking System

A Java-based railway ticket booking project developed for **PROGRAMMING QUEST**. The repository contains two versions of the application: a **console-based system** and a **Java Swing graphical application**.

## Project Overview

The project demonstrates how the same railway booking workflow can be presented through two different user interfaces:

- **– Console Application:** Interact with the booking system through a text-based menu in the terminal.
- **– GUI Application:** Use a desktop interface built with Java Swing to manage bookings and view seat availability visually.

## Features

### Console-Based Application
- Terminal-based interaction for railway ticket booking.
- Train and seating information presented through the console.
- Java-based implementation of the booking workflow.

### Java Swing Application
- Desktop graphical user interface using Java Swing.
- Visual display of carriage and seat arrangements.
- Seat status display to distinguish available and booked seats.
- Booking interaction through the GUI.
- Support for express trains with different numbers of carriages and seats per carriage.

## How to Run

### Prerequisites

- Java Development Kit (JDK)
- A terminal or a Java IDE such as Visual Studio Code, IntelliJ IDEA, or Eclipse

### Quest 03 – Console Version

1. Open the `Console` folder in your Java IDE.
2. Locate the Java file containing `public static void main(String[] args)`.
3. Run that file and follow the console prompts.

### Quest 04 – GUI Version

1. Open the `GUI` folder in your Java IDE.
2. Locate the Java file containing `public static void main(String[] args)`.
3. Run that file to launch the Swing interface.
4. Use the interface to view seats and perform bookings.

> **Note:** If the project uses Java packages or multiple source folders, preserve its existing directory structure when importing it into your IDE.
