HOW TO RUN
1. Install Java JDK 8 or newer.
2. Extract the ZIP and open the CO2210_Quest04 folder.
3. Run run.bat on Windows, or use the terminal commands:
   javac -encoding UTF-8 -d out src\*.java
   java -cp out Main

FUNCTIONS
- View train timetable
- View carriages and available/booked seats
- Book a maximum of four seats
- Find, modify and cancel bookings
- See booking records for each train
- Save bookings in CSV files

SEAT COLOURS
Green = available
Light red with a cross = booked
Amber with a check mark = selected

The train times are example data. No payments are included.
All interface elements are made with Java Swing code.
